# sendol's CS & Dev. Blog

Personal CS / development blog built with [Astro](https://astro.build/) and the [Fuwari](https://github.com/saicaca/fuwari) theme.

## Development

```bash
pnpm install
pnpm dev
```

Production build:

```bash
pnpm build
```

Posts live in `src/content/posts/`, and static post assets live in `public/assets/`.

The site is deployed to GitHub Pages at <https://sendoru.github.io/>.
